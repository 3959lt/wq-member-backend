入门指南

快速开始

  1. 在「购买套餐」查看价格、有效天数与流量，创建订单。
  2. 用支付宝扫描付款页的收款码，填写正确金额并备注订单编号；等待管理员核实到账。
  3. 会员开通后，在「我的订阅」生成链接并复制。重置会使旧链接失效。
  4. 在兼容 Mihomo 的客户端导入订阅，更新配置，选择服务节点与规则模式。
  5. 开启客户端系统代理，再访问网页测试连接。需要代理所有应用时，可按客户端文档了解 TUN 模式。
订阅链接包含连接凭证，请勿公开。若通过 localhost 隧道生成链接，它只适用于该电脑；请通过可访问的服务地址获取订阅。
Windows

Windows 客户端导入

  1. 从 Clash Verge Rev 官方文档进入下载页面，选择与你的 Windows 系统相符的版本。
  2. 安装并启动客户端，在订阅 / 配置页面添加远程配置，粘贴本站订阅链接后导入。
  3. 选中刚导入的配置，查看「服务节点」策略组并选择本站节点。
  4. 将代理模式切为「规则」，开启系统代理。国内、苹果和微软默认直连。
  5. 修改套餐或分流规则后，更新订阅；客户端界面名称可能随版本变化。

详细操作与版本差异以 客户端官方教程为准。

macOS

macOS 客户端导入

  1. 在 Clash Verge Rev 官方文档下载适合你的 Mac 的版本，注意 Apple Silicon 与 Intel 的区别。
  2. 启动客户端，添加远程订阅，粘贴本站链接并完成导入。
  3. 启用该配置，选择服务节点，使用规则模式并开启系统代理。
  4. 系统代理不一定接管所有应用；TUN 模式所需权限与设置请查阅客户端官方教程。

手机端需使用支持本站 VMess 与规则订阅格式的客户端，实际兼容性需单独验证。

连接规则

规则模式怎么工作？

规则模式按域名和 IP 决定连接去向。国内域名与国内 IP 默认直连；苹果和微软服务默认直连；其他服务根据分类和兜底策略使用服务节点。国内域名覆盖以客户端分类数据库为准。

DIRECT / 直连
通过你当前的本地网络访问。
服务节点
通过本站提供的节点转发。
REJECT / 拒绝
阻止命中规则的连接。

管理员自定义规则优先。更新订阅后，客户端可能保留旧的策略组选择；如苹果或微软仍走代理，请手动改为 DIRECT。首次加载地理分类可能需要下载数据库。

规则语法参考 Mihomo 官方规则文档。

套餐与订单

付款、有效期和流量

当前收款采用支付宝固定收款码，金额需手动填写，到账由管理员确认。付款页刷新的是本站订单状态，不会自动读取支付宝账单。

  1. 确认收款后，订单中的有效天数与流量额度一起分配。
  2. 会员未过期：有效期顺延，有限剩余流量与新额度叠加。
  3. 会员已过期：从确认时重新计算有效期，只分配新套餐额度。
  4. 累计用量会保留，仪表盘显示当前剩余额度。不限量套餐转有限套餐按新额度执行。
  5. 流量耗尽、会员过期或账号停用后，节点连接权限会暂停。

付款后请保留交易记录，联系管理员时提供订单编号、付款时间与交易单号；不要提供支付宝密码。

帮助中心

常见问题

已经付款，为什么还没开通？

收款需人工核对。请提供订单编号与付款记录，等待管理员确认。确认后节点通常在 15–30 秒内同步权限。

订阅更新失败或提示 403？

检查会员是否有效、流量是否耗尽、订阅或账号是否停用。链接重置后需重新导入。确认订阅地址不是其他电脑不可访问的 localhost 地址。

节点正常，但某些应用不走代理？

确认客户端启用正确配置和规则模式。系统代理只影响遵循系统代理设置的应用，其他应用的接管方式请查客户端教程。

如何判断某个域名是否走代理？

查看客户端连接记录中的命中规则与策略：DIRECT 为直连，本站节点为转发。全局模式会改变规则分流行为。

流量统计会立即更新吗？

统计由节点定期采样，通常约 15 秒更新。它是上传加下载的累计数据，不等于实时网速；异常退出时最后一段采样可能有少量误差。

订阅链接泄露怎么办？

重置订阅链接以停止旧链接下载，并联系管理员重置节点凭证。仅重置链接无法撤销已经导入的节点凭证。
