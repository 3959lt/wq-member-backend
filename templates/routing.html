分流规则

这些规则控制用户客户端的流量去向，适用于所有订阅。规则按从上到下的顺序匹配，第一条匹配生效；未匹配的流量使用服务节点。

保存后，用户需要更新 Clash / Mihomo 订阅，选择「规则模式」。客户端已保存的分类选择可能覆盖这里的默认选择；请在客户端同步调整。DIRECT 使用用户本地网络，服务节点使用你的服务器，REJECT 拒绝连接。

优先匹配的自定义规则

每行一条，优先于基础规则。域名填写为 example.com，不带 https:// 或路径。DOMAIN 只匹配该域名；DOMAIN-SUFFIX 包括子域名。

可用目标：服务节点、DIRECT、REJECT，以及下方的分类名称。支持 DOMAIN / DOMAIN-SUFFIX / DOMAIN-KEYWORD / IP-CIDR / IP-CIDR6 / GEOIP / PROCESS-NAME；进程规则取决于客户端权限。最多 1000 条。最后的 MATCH 规则由系统自动生成。

基础列表参考所提供订阅，已移除原供应商专用规则与节点凭证。域名列表和 IP 归属可能变化；你可以在上方添加优先规则修正。GEOSITE 使用客户端的域名分类数据库，GEOIP 使用客户端的 IP 数据；首次加载可能需要下载。国内域名覆盖以分类数据库为准。
